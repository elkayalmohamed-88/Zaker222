# أذكاري — مشروع APK جاهز لـ GitHub

هذا المشروع مبني على ملف `Azkari_Professional_Premium.html` المرفوع، مع إضافة طبقة PWA وCapacitor لتحويله إلى تطبيق Android.

## أسرع طريقة لبناء APK
1. أنشئ مستودع GitHub جديد.
2. ارفع **كل محتويات هذا المجلد** إلى المستودع (وليس المجلد نفسه).
3. افتح تبويب **Actions**.
4. شغّل workflow باسم **Build Android APK**.
5. بعد نجاح البناء، ادخل إلى صفحة الـ workflow وافتح **Artifacts** ثم حمّل `azkari-debug-apk`.

## ملاحظات
- التطبيق يحتفظ بمنطق وبيانات HTML الأصلية؛ لم أعد كتابة وظائف الأذكار أو العدادات.
- الملف الأصلي يستخدم Tailwind وFont Awesome وGoogle Fonts من CDN، لذلك أول تشغيل يحتاج اتصالًا بهذه الموارد، وبعدها يحاول Service Worker تخزينها مؤقتًا عندما تسمح بيئة التشغيل بذلك.
- بيانات التطبيق الأصلية تعتمد على `localStorage`، وتوجد في الملف وظائف للتصدير والاستيراد والتصفير اليومي.
